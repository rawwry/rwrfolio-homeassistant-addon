Home Assistant Integration

Binde dein Krypto-Portfolio nahtlos in dein Smart Home Dashboard auf Home Assistant OS (z.B. Raspberry Pi / NUC / Synology) ein.

Live JSON Endpoint aufrufen

1. Home Assistant configuration.yaml 

# In deiner Home Assistant configuration.yaml einfügen:
sensor:
  - platform: rest
    name: "Crypto Portfolio"
    resource: "http://:8000/api/homeassistant/sensors"
    scan_interval: 300 # Alle 5 Minuten abfragen
    json_attributes_path: "$.portfolio"
    json_attributes:
      - total_value_eur
      - total_invested_eur
      - total_pnl_eur
      - total_pnl_percentage
      - asset_count
      - top_asset
    value_template: "{{ value_json.portfolio.total_value_eur }}"
    unit_of_measurement: "EUR"
    device_class: monetary
    state_class: total

  - platform: rest
    name: "Crypto Bitcoin"
    resource: "http://:8000/api/homeassistant/sensors"
    scan_interval: 300
    json_attributes_path: "$.assets.BTC"
    json_attributes:
      - balance
      - value_eur
      - invested_eur
      - avg_buy_price_eur
      - current_price_eur
      - pnl_eur
      - pnl_percentage
    value_template: "{{ value_json.assets.BTC.value_eur }}"
    unit_of_measurement: "EUR"
    device_class: monetary

    name: Gesamtwert
